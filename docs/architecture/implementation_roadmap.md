# Implementation Roadmap

## Phase 1 — Foundation

- Initialize the Next.js 15 application.
- Configure TypeScript, Tailwind, shadcn/ui, ESLint, and Prettier.
- Create Supabase project and environment variables.

## Phase 2 — Core Renderer

- Build the generic Konva-based renderer.
- Introduce metadata loading and wheel placement logic.
- Verify the MVP vehicle renders correctly without vehicle-specific code.

## Phase 3 — Catalog and Admin

- Implement vehicle, wheel, and tyre catalog APIs.
- Add admin upload and publish workflows.
- Create preview and validation experience for admins.

## Phase 4 — Dealer Experience

- Add dealer-facing selection UI.
- Support reset, save, and quote workflows.
- Add tenant branding and inventory support.

## Phase 5 — Scale and AI

- Add asset optimization, CDN delivery, and monitoring.
- Introduce AI-assisted asset pipeline with human review.
- Expand to additional vehicles and dealer accounts.
