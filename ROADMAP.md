# Roadmap

## Phase 1 — Foundation

- Establish scalable folder structure and linting/tooling.
- Add typed environment configuration and central logging.
- Introduce test and CI infrastructure.

## Phase 2 — Product Experience

- Expand the preview workflow and add richer dealer UI.
- Build catalog APIs for vehicles, wheels, and tyres.
- Introduce admin workflows with publish validation.

## Phase 3 — Scale and Operations

- Add tenant-specific data access and operational observability.
- Introduce storage-backed assets and analytics.
- Expand end-to-end coverage and deployment hardening.
